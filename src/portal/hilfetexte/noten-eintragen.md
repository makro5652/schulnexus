Es gibt drei Wege, Noten einzutragen. Alle prüfen Ihre Eingaben sofort und speichern nur, wenn alles gültig ist.

| Weg | Gut für |
| --- | --- |
| **Noten eintragen** (Schnelleingabe) | einen Leistungsnachweis für die ganze Klasse, zum Beispiel eine Klassenarbeit |
| **Noten nach Klasse** (Notentabelle) | viele Leistungsnachweise auf einmal, Überblick wie in Excel |
| **Excel-Notentabelle** | offline arbeiten, siehe [Excel-Notentabelle](hilfe:excel-notentabelle) |

## Eingabeschreibweisen

| Eingabe | Bedeutung |
| --- | --- |
| `2+`, `2`, `2-` (Sek II: `15` … `0`) | Note der Skala |
| `34`, `34,5` | erreichte BE, wenn ein Notenschlüssel gewählt ist; die Note wird berechnet und angezeigt |
| `=2+` | Note direkt, auch bei Notenschlüssel |
| `e`, `u`, `b`, `nb` | entschuldigt, unentschuldigt, befreit, nicht bewertbar |
| `u 6` | unentschuldigt mit Note |
| leer | keine Note |

„Unentschuldigt“ ohne Note zählt als 6 bzw. 0 Punkte (je Skala einstellbar).

## Schnelleingabe Schritt für Schritt

1. **Unterricht › Mein Unterricht**: Kurs wählen, **Noten eintragen**.
2. Oben **Ordner** wählen (zum Beispiel „Klassenarbeiten“), **Bezeichnung** (frühere Bezeichnungen werden vorgeschlagen), **Datum** (muss im Halbjahr liegen) und **Gewicht**. Bei einem Prozent-Ordner zeigt die Seite, wie viel Prozent schon vergeben sind.
3. Optional **Bewertung über BE**: Notenschlüssel und Höchstzahl der BE wählen; dann tragen Sie BE ein und die Note wird berechnet.
4. Noten eintippen: [[Enter]] oder [[↓]] springt zur nächsten Zeile, [[↑]] zur vorigen. Eine Notenspalte aus Excel lässt sich in das erste Feld einfügen.
5. **Speichern** ([[Strg]]+[[S]]) oder **Speichern und nächsten anlegen** ([[Strg]]+[[Enter]]).

Hilfen auf der Seite:

- **Statistik** rechts: Durchschnitt, Verteilung, Zahl der Vermerke und noch fehlenden Einträge – nur zur Orientierung.
- **Name suchen** und **nur ohne Note** blenden Zeilen aus; [[Esc]] leert den Filter. Ausgeblendete Zeilen werden trotzdem gespeichert.
- **Einzelgewichte anzeigen:** abweichendes Gewicht für eine einzelne Note (zum Beispiel verkürzte Nachschreibarbeit) – mit Begründung.
- **Entwurf:** Ungespeicherte Eingaben merkt sich der Browser bis zum Schließen des Fensters. Nach versehentlichem Neuladen bietet die Seite „Wiederherstellen“ an.
- [[F1]] zeigt alle Tastenkürzel.

Ist eine Eingabe ungültig, wird **nichts** gespeichert und die Zeile rot markiert.

## Notentabelle (Noten nach Klasse)

1. **Unterricht › Noten nach Klasse**, Halbjahr wählen, Klasse antippen.
2. Fach-Kachel antippen. Die Tabelle zeigt Schüler:innen untereinander und Leistungsnachweise nebeneinander, rechts die Schnitte und Tendenz.
3. Zellen direkt bearbeiten; geänderte Zellen sind markiert. **Speichern** übernimmt alles auf einmal. Was inzwischen jemand anderes geändert hat, wird nicht überschrieben.
4. **+ Klassenarbeit** bzw. **+ SoMi-Note** legt sofort eine neue Spalte mit heutigem Datum an (bis zur Höchstzahl der Notenregel). Das **Gewicht** jeder Spalte steht im Tabellenkopf und lässt sich direkt ändern.
5. **Zeugnisnote** in der letzten Spalte: „auto“ = gerundete Note aus den Einzelnoten (rechnet mit), oder eine Note festsetzen.

Leistungsnachweise mit Notenschlüssel und gesperrte Schüler:innen sind in der Tabelle nur lesbar.

## Bewertungsstruktur

Notenübersicht › **Bewertungsstruktur**: Ordner anlegen, umbenennen, verschieben („Liegt in“, bis fünf Ebenen), Gewichte ändern. Je Ebene wählen Sie die **Gewichtsart**: relativ (2 : 1, 50 : 50) oder Prozent (die Seite zeigt, was bis 100 % fehlt). Leere Ordner werden bei der Berechnung übersprungen.

- **Kopieren:** Struktur von einem anderen Kurs übernehmen oder auf Parallelklassen übertragen.
- **Jahresnote (Jahrgang 5–10):** Im 2. Halbjahr zählt das 1. Halbjahr standardmäßig 40 %. Anteil und Grundlage (Schnitt oder Halbjahreszeugnisnote) stellen Sie hier ein.
- Gibt eine **Notenregel** feste Bereiche vor (zum Beispiel Klassenarbeiten 50 % / Sonstige Mitarbeit 50 %), lassen sich diese nicht umbenennen oder umgewichten; darunter gliedern Sie frei.

## Rundung und Zeugnisnote

- **Rundung zugunsten der Schüler:innen:** Ein Schnitt von genau x,50 ergibt die bessere Note (Ø 2,50 → 2).
- Die **Zeugnisnote** gilt automatisch aus den Einzelnoten, solange niemand eine Note festsetzt. Weicht eine festgesetzte Note vom Vorschlag ab, wird das nur farbig markiert – die Lehrkraft hat die Notenhoheit.
- **Gesperrte Noten** (nach Konferenz oder Zeugnisfreigabe) lassen sich nicht ändern, siehe [Notensperre und Notenschluss](hilfe:notensperre).

## Ausgeben

In der Notenübersicht: **Excel** (alle Noten, Ordnerschnitte, Vorschlag, Zeugnisnote) und **Notenbogen (PDF)** mit Kursübersicht und je Schüler:in einem Bogen samt Rechenweg. „PDF“ neben einem Namen erzeugt nur diesen Bogen.
